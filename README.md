# GlossyBar

Bring the Aqua menu bar back to your Mac.

- **The Tiger gloss, pixel for pixel.** The Mac OS X 10.4 gradient, measured from the real thing, blended live over your menu bar.
- **Your menu bar, not a replacement.** Titles, icons and clock stay exactly where they are. Clicks go straight through.
- **Every display, every space.** Notched MacBooks, external monitors, Mission Control, space swipes. It just holds.
- **Light or dark, automatically.** Silver Aqua over light wallpapers, graphite over dark ones. Override it if you like.
- **A soft shadow underneath.** Optional, subtle, and hidden behind your windows.
- **Nothing to configure.** On/off, Bar Tone, Shadow, Open at Login. That's the whole menu.
- **Light on your Mac.** Under 2% CPU, no Screen Recording permission, no hacks to system files.
- **Stays fresh.** Built-in updates via Sparkle.

## Install

Download the latest DMG from [Releases](https://github.com/MartinRybergLaude/glossybar/releases), drag GlossyBar to Applications, open it.

## Build from source

```sh
make run     # builds dist/GlossyBar.app and launches it
```
