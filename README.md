# GlossyBar

Bring the Aqua menu bar back to your Mac.

## Install

Download the latest DMG from [Releases](https://github.com/MartinRybergLaude/glossybar/releases), drag GlossyBar to Applications, open it.

## Build from source

```sh
make run     # builds dist/GlossyBar.app and launches it
```

Curious how it's done? See [docs/INTERNALS.md](docs/INTERNALS.md).
